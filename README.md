# Brazilian E-Commerce SQL Analysis

## 📌 Project Overview

This project analyzes a Brazilian e-commerce dataset using PostgreSQL.

The goal of this project is to practice SQL fundamentals and answer practical business questions related to customers, orders, products, sales, and purchasing patterns.

This is an entry-level SQL portfolio project focused on building strong foundations in data analysis.

## 🛠️ Tools Used

- PostgreSQL
- pgAdmin 4
- SQL
- GitHub

## 📊 Dataset

The project uses a Brazilian e-commerce dataset containing information about customers, orders, products, and order items.

The dataset was imported into PostgreSQL and organized into related tables for analysis.

## 🗂️ Main Tables

The analysis uses several related tables, including:

- `customers` — customer information and location
- `orders` — order information and purchase timestamps
- `order_item` — products and prices associated with orders
- `products` — product information and categories

## 🔍 Business Questions

The SQL analysis answers questions such as:

- Which customers have placed the most orders?
- Which cities have the most customers?
- Which customer states have the most customers?
- Which product categories generate the highest sales?
- Which months have the highest and lowest sales?
- Which states generate the highest sales?
- Which customers have the highest total spending?
- Which states have the highest average item prices?
- Which states have more than 1,000 customers?
- Which are the top 5 customer states by customer count?

## 🧠 SQL Concepts Practiced

This project demonstrates practical use of:

- `SELECT`
- `WHERE`

- `COUNT()`
- `SUM()`
- `AVG()`
- `GROUP BY`
- `HAVING`
- `ORDER BY`

- `DATE_TRUNC()`

## 📈 Key Findings

The analysis showed differences in customer activity, sales performance, and purchasing patterns across Brazilian states and product categories.

Some of the analysis included identifying:

- The states with the largest customer bases
- The highest-selling product categories
- Months with particularly high sales
- Customers with high total spending
- States with higher average item prices
